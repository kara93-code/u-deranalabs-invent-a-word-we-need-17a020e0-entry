Invent a Word We Need — one invented English word, defined in a single clear line: **Canceljoy** — the quiet relief when a plan is cancelled and your evening is suddenly yours again.

## Run it

```sh
node main.ts
```

The program writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It is deterministic, stdlib-only, and makes no network calls.
